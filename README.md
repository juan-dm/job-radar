# Job Radar (working name)

Early-career tech job radar for the UK, Spain, Germany, France and the Netherlands. It pulls internship, graduate and junior listings straight from company job-board feeds, and an AI agent works out who can apply to each one.

**Status:** early setup. The full README (demo, architecture, decisions, eval results) comes later.

## Run locally

Needs Node.js 20.9 or newer.

```bash
npm install
npm run dev   # then open http://localhost:3000
```
